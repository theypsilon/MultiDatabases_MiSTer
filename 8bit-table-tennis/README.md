# 8-Bit Table Tennis database

- Database ID:
  [`MultiDatabases/8bit-table-tennis`](https://theypsilon.github.io/DB-Inspector_MiSTer/?database-url=https%3A%2F%2Fraw.githubusercontent.com%2Ftheypsilon%2FMultiDatabases_MiSTer%2Fdb%2F8bit-table-tennis%2Fdb.json)
- Upstream:
  [`mike42/8bit-table-tennis`](https://github.com/mike42/8bit-table-tennis)
- Database URL:
  `https://raw.githubusercontent.com/theypsilon/MultiDatabases_MiSTer/db/8bit-table-tennis/db.json`

The generator follows the latest GitHub release and installs its
`table_tennis_*.nes` asset in `games/NES`. Successive versioned ROM filenames
are entangled so an update removes the superseded version. The game is
distributed under the MIT license.

## Installation

Download
[`downloader_MultiDatabases_8bit-table-tennis.zip`](https://raw.githubusercontent.com/theypsilon/MultiDatabases_MiSTer/db/8bit-table-tennis/downloader_MultiDatabases_8bit-table-tennis.zip),
extract it to `/media/fat` on the MiSTer SD card, and run the MiSTer updaters.

No `MiSTer.ini` changes, BIOS files, or additional game files are required.
Launch the game with the standard NES core.
